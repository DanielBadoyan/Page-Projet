MIAGE Connect

La plateforme collaborative destinée aux étudiants de L3, M1 et M2 MIAGE : faciliter l'entraide, partager ses connaissances et ne plus rester bloqué seul face à une difficulté universitaire.

Dossier de projet (PDF) Code source Versions

Le projet

Lorsqu'un étudiant rencontre une difficulté pédagogique, la recherche d'aide est souvent dispersée entre les groupes de discussion, les échanges informels et des ressources éparses. MIAGE Connect centralise l'entraide entre promotions (L3, M1, M2 et mentors) et calcule des mises en relation pertinentes plutôt que de simplement stocker des annonces : trouver un pair qui maîtrise une notion, former des binômes complémentaires, planifier des séances de révision et éviter les questions en doublon.

Architecture

Front web (React) → API REST (Spring Web, documentée avec OpenAPI / Swagger) → back Java / Spring Boot avec couche algorithmique découplée → MySQL via Spring Data JPA / Hibernate. Tests unitaires et d'intégration (JUnit 5), conteneurisation Docker et intégration continue via GitHub Actions.
